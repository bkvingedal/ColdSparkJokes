# ColdSpark Jokes

A simple, single-page web application that displays jokes about "ColdSpark scientists."

## How to Use

1.  Clone this repository to your local machine.
2.  Open the `index.html` file in your favorite web browser.
3.  Click the "Get New Joke" button to see a new joke.

## Features

*   Displays a random joke from a predefined list.
*   Shows the joke's setup first, followed by a 5-second countdown.
*   Reveals the punchline after the countdown.
*   A "Get New Joke" button to fetch a new joke.

## Technologies Used

*   HTML
*   CSS
*   JavaScript

## Project Structure

*   `index.html`: The main file containing the HTML structure, CSS styles, and JavaScript logic.
